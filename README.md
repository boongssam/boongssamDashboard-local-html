# 붕쌤 학급 대시보드 — 로컬 html 버전

서버(Next.js) 없이 `index.html`을 그냥 더블클릭해서 여는 버전입니다.

## 사용법

1. **크롬 또는 엣지**로 `index.html`을 엽니다. (파일 탐색기에서 더블클릭)
2. 처음 열면 "데이터를 저장할 폴더를 선택해주세요" 화면이 뜹니다. 빈 폴더(또는 새로 만든 폴더)를 하나 골라주세요. 그 폴더 안에 `db.json` 파일이 생기고, 앞으로 모든 데이터(학생/출석/공지/과제 등)가 여기에 저장됩니다.
3. 우측 상단 "🔒 학생" 버튼을 눌러 처음 사용 시 선생님 비밀번호를 설정합니다.
4. 설정(⚙️) 메뉴에서 Gemini API 키를 입력하면 AI 종합의견 기능을 쓸 수 있습니다.
5. 학생 명단은 "학생 관리" 페이지의 "엑셀 업로드" 버튼으로 가져올 수 있습니다.

## 꼭 알아야 할 점

- **크롬/엣지 전용**입니다. 폴더에 직접 읽고 쓰는 기능(File System Access API)이 이 두 브라우저에만 있어서, 파이어폭스·사파리에서는 폴더 선택 화면 자체가 동작하지 않습니다.
- **브라우저를 완전히 껐다 켜면** 보안 정책상 폴더 접근을 다시 허용해야 할 수 있습니다(버튼 한 번 클릭). 폴더를 다시 찾아 들어갈 필요는 없고, "다시 연결하기" 버튼만 누르면 됩니다.
- **서버가 없어서** 선생님 비밀번호와 Gemini API 키가 선택한 폴더의 `db.json`에 평문으로 저장됩니다. 이 컴퓨터를 다른 사람과 같이 쓴다면 주의하세요.
- 첫 실행 시 React/엑셀 처리 라이브러리 등을 인터넷(CDN)에서 받아옵니다. 이후에는 브라우저 캐시로 어느 정도 재사용되지만, 완전한 오프라인 보장은 아닙니다. Gemini AI, NEIS 급식/학사일정 조회는 매번 인터넷이 필요합니다.
- 대시보드 위젯은 **선생님 모드**에서 "배치 편집"을 누르면 옮기기 버튼으로 자리를 바꾸고, 오른쪽 아래 모서리로 크기를 조절할 수 있습니다(키보드: 옮기기 버튼에서 화살표 = 이동, Shift+화살표 = 크기). 배치는 `db.json`의 `settings.dashboardLayouts`에 저장되고, "기본 배치로"로 되돌릴 수 있습니다. 화면이 좁으면(태블릿 세로·휴대폰) 한 줄로 쌓이고 편집은 꺼집니다.

## 파일 구성

- `index.html` — 전체를 띄우는 진입점 (CDN에서 React/ReactDOM/엑셀 라이브러리를 불러옴)
- `local.js` — 폴더 읽기/쓰기, NEIS, Gemini 직접 호출, 엑셀 처리, 날짜 등 순수 JS 유틸 (IIFE로 감싸서 전역 이름 충돌 방지)
- `app.jsx` — 전체 화면/로직 원본 소스 (사람이 수정하는 파일)
- `app.js` — `app.jsx`를 Babel로 미리 컴파일해둔 결과물 (브라우저가 실제로 불러오는 파일)
- `styles.css` — 기본 스타일
- `theme.css` — 현재 디자인(색·글꼴·대시보드 위젯). `styles.css` 다음에 불러와 덮어씀

`index.html`을 옮길 때는 **이 폴더 전체를 통째로** 옮겨야 합니다 (`local.js`, `app.js`, `styles.css`가 같은 폴더에 있어야 함).

### app.jsx를 수정했다면

`app.jsx`는 JSX 문법이라 브라우저가 직접 실행할 수 없고, 반드시 `app.js`로 다시 컴파일해야 변경사항이 반영됩니다. (처음엔 브라우저에서 즉석으로 변환하는 방식이었는데, `file://`로 열었을 때 그 방식 자체가 크롬 보안 정책에 막혀서 지금처럼 미리 컴파일하는 방식으로 바꿨습니다.)

```bash
npx --yes --package=@babel/core@7.26.0 --package=@babel/cli@7.25.9 --package=@babel/preset-react@7.25.9 \
  babel app.jsx --presets=@babel/preset-react --no-babelrc --out-file app.js
```
