# 붕쌤 학급 대시보드 — 로컬 html 버전

서버(Next.js) 없이 `index.html`을 그냥 더블클릭해서 여는 버전입니다.

## 사용법

1. **크롬 또는 엣지**로 `index.html`을 엽니다. (파일 탐색기에서 더블클릭)
2. 처음 열면 "데이터를 저장할 폴더를 선택해주세요" 화면이 뜹니다. 빈 폴더(또는 새로 만든 폴더)를 하나 골라주세요. 그 폴더 안에 `db.json` 파일이 생기고, 앞으로 모든 데이터(학생/출석/공지/과제 등)가 여기에 저장됩니다.
3. 우측 상단 "🔒 학생" 버튼을 눌러 처음 사용 시 선생님 비밀번호를 설정합니다.
4. 설정(⚙️) 메뉴에서 Gemini API 키를 입력하면 AI 종합의견 기능을 쓸 수 있습니다.
5. 학생 명단은 "학생 관리" 페이지의 "엑셀 업로드" 버튼으로 가져올 수 있습니다.

## 꼭 알아야 할 점

- **크롬/엣지 전용**입니다. 폴더에 직접 읽고 쓰는 기능(File System Access API)이 이 두 브라우저에만 있어서, 파이어폭스·사파리에서는 폴더 선택 화면 자체가 동작하지 않습니다.
- **브라우저를 완전히 껐다 켜면** 보안 정책상 폴더 접근을 다시 허용해야 할 수 있습니다(버튼 한 번 클릭). 폴더를 다시 찾아 들어갈 필요는 없고, "다시 연결하기" 버튼만 누르면 됩니다. 데이터 폴더를 다른 곳으로 옮겼다면 같은 화면의 **"다른 폴더 선택"** 이나, 선생님 모드 ⚙️ 설정의 **데이터 폴더 → "다른 폴더 선택"** 으로 새 위치를 고르세요.
- **서버가 없어서** 선생님 비밀번호와 Gemini API 키가 선택한 폴더의 `db.json`에 평문으로 저장됩니다. 이 컴퓨터를 다른 사람과 같이 쓴다면 주의하세요.
- 첫 실행 시 React/엑셀 처리 라이브러리 등을 인터넷(CDN)에서 받아옵니다. 이후에는 브라우저 캐시로 어느 정도 재사용되지만, 완전한 오프라인 보장은 아닙니다. Gemini AI, NEIS 급식/학사일정 조회는 매번 인터넷이 필요합니다.
- 대시보드 위젯은 **선생님 모드**에서 "배치 편집"을 누르면 옮기기 버튼으로 자리를 바꾸고, 오른쪽 아래 모서리로 크기를 조절할 수 있습니다(키보드: 옮기기 버튼에서 화살표 = 이동, Shift+화살표 = 크기). 배치는 `db.json`의 `settings.dashboardLayouts`에 저장되고, "기본 배치로"로 되돌릴 수 있습니다. 화면이 좁으면(태블릿 세로·휴대폰) 한 줄로 쌓이고 편집은 꺼집니다.

## 파일 구성

- `index.html` — 전체를 띄우는 진입점 (CDN에서 React/ReactDOM/엑셀 라이브러리를 불러옴)
- `local.js` — 폴더 읽기/쓰기, NEIS, Gemini 직접 호출, 엑셀 처리, 날짜 등 순수 JS 유틸 (IIFE로 감싸서 전역 이름 충돌 방지)
- `app.jsx` — 전체 화면/로직 원본 소스 (사람이 수정하는 파일)
- `app.js` — `app.jsx`를 Babel로 미리 컴파일해둔 결과물 (브라우저가 실제로 불러오는 파일)
- `styles.css` — 기본 스타일
- `theme.css` — 현재 디자인(색·글꼴·대시보드 위젯). `styles.css` 다음에 불러와 덮어씀

`index.html`을 옮길 때는 **이 폴더 전체를 통째로** 옮겨야 합니다 (`local.js`, `app.js`, `styles.css`가 같은 폴더에 있어야 함).

### app.jsx를 수정했다면

`app.jsx`는 JSX 문법이라 브라우저가 직접 실행할 수 없고, 반드시 `app.js`로 다시 컴파일해야 변경사항이 반영됩니다. (처음엔 브라우저에서 즉석으로 변환하는 방식이었는데, `file://`로 열었을 때 그 방식 자체가 크롬 보안 정책에 막혀서 지금처럼 미리 컴파일하는 방식으로 바꿨습니다.)

```bash
npx --yes --package=@babel/core@7.26.0 --package=@babel/cli@7.25.9 --package=@babel/preset-react@7.25.9 \
  babel app.jsx --presets=@babel/preset-react --no-babelrc --out-file app.js
```

## 테스트/둘러보기 모드

`index.html?mock=1`로 열면 실제 폴더 선택 없이 메모리상의 가짜 데이터로 바로 둘러볼 수 있습니다. 같은 탭에서는 새로고침해도 유지되고 탭을 닫으면 초기화되니, 실제 사용 시에는 꼭 `?mock=1` 없이 여세요.

## 학생에게 QR로 공유하기 (Vercel)

학생 폰에는 선생님 데이터 폴더가 없으므로, 선생님 앱이 **학생에게 보여줄 내용만** 골라 Vercel에 자동으로 올리고, 학생은 `https://<배포 주소>/?student` 를 읽기 전용으로 봅니다(폴더 연결 화면 없음).

- 올라가는 것: 시간표(주간 일정), D-Day, 공지사항, 칭찬 온도계, 칭찬 랭킹(상위 5명 이름·점수), 바로가기. 급식은 학생 화면이 NEIS에서 바로 가져옵니다.
- 올라가지 않는 것: 전화번호, 알레르기, 생일, 출결, 학생 기록, 비밀번호, API 키.

처음 한 번 설정:
1. Vercel 프로젝트 → **Storage** → **Create** → **Blob** 저장소를 만들고 이 프로젝트에 연결합니다 (`BLOB_READ_WRITE_TOKEN` 자동 추가).
2. Vercel 프로젝트 → **Settings → Environment Variables** 에 `STUDENT_PUBLISH_KEY` 를 아무도 모를 긴 값으로 추가합니다.
3. **Deployments** 에서 다시 배포(Redeploy)합니다.
4. 선생님 앱 ⚙️ 설정의 **학생 화면 공유 키** 에 2번과 같은 값을 넣고 저장합니다. (`index.html` 을 파일로 연다면 **배포 주소** 칸도 채웁니다.)
5. 설정 창에 나오는 학생용 주소로 QR을 만듭니다.

이후 선생님이 내용을 바꾸면 자동으로 올라갑니다. Vercel 무료(Hobby) 한도를 넘지 않도록 올리기는 최소 5분 간격, 학생 화면 응답은 3분씩 캐시되므로 학생 화면에는 보통 몇 분 안에 반영됩니다.

## 교실 서버로 공유하기 (인터넷에 안 올리는 방법)

선생님 컴퓨터를 켜 두면 **같은 학교망**에 연결된 학생 폰이 학생 화면을 볼 수 있습니다. 데이터는 인터넷에 올라가지 않고, 서버가 데이터 폴더의 `db.json` 을 직접 읽어 학생용 항목만 보여주므로 바꾸면 바로(30초 안) 반영됩니다.

```bash
npm install
node server.js
```

또는 폴더의 **`서버 켜기.bat`** 을 더블클릭하면 됩니다(처음이면 `npm install` 도 알아서 하고, 2초 뒤 선생님 화면을 엽니다). 바탕화면에 바로가기를 만들어 두면 편합니다. 검은 창을 닫으면 서버가 꺼지니 수업 중에는 최소화만 해 두세요.

- `npm install` 은 처음 한 번만 하면 됩니다. React 같은 화면 라이브러리를 이 컴퓨터에 받아 두어, 학생 Wi-Fi에서 외부 사이트(unpkg)가 막혀 있어도 서버가 직접 보내 줍니다.
- 데이터 폴더 기본값은 `바탕화면\data-dashboard` 입니다. 다른 곳이면 `node server.js "폴더 경로"` (포트까지: `node server.js "폴더 경로" 8081`).
- 실행하면 `학생 QR 주소: http://10.x.x.x:8080/?student` 가 나옵니다. 이 주소로 QR을 만드세요. 학생이 주소만 입력해도 학생 화면으로 바로 갑니다.
- 처음 한 번 Windows 방화벽에서 이 포트를 허용해야 합니다 (관리자 PowerShell):
  `New-NetFirewallRule -DisplayName "학급 대시보드 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow -Profile Any`
- 서버가 보내는 파일은 화면 파일 6개(`index.html`, `app.js`, `local.js`, `student-snapshot.js`, `styles.css`, `theme.css`)와 학생용 내용뿐입니다.
- **활동 완료 체크:** 학습 관리의 가장 최근 활동이 학생 화면 맨 위에 나오고, 학생이 자기 이름을 눌러 "끝냈어요"를 보낼 수 있습니다. 체크는 데이터 폴더의 `checks/` 에 한 건씩 저장되고, 선생님 앱이 열려 있으면 5초마다 학습 관리에 반영한 뒤 지웁니다. **지난 활동**도 아래 목록에서 펼쳐 보고, 늦게 끝낸 학생이 체크할 수 있습니다(최근 60개). 학생은 완료만 보낼 수 있고, 취소는 선생님 화면에서 이름을 길게 눌러 합니다. (교실 서버에서만 되고, Vercel 학생 화면에는 나오지 않습니다)
- **투표/설문:** 학급 도구에서 만든 진행 중인 투표가 학생 화면에 나오고, 학생이 폰으로 항목을 골라 투표할 수 있습니다. 한 폰에서 한 투표에 한 번만 낼 수 있고(서버를 다시 켜면 이 기록은 초기화), 표는 데이터 폴더의 `votes/` 에 한 표씩 저장된 뒤 선생님 앱이 5초마다 더해 반영합니다. 누가 어디에 냈는지는 남지 않습니다. (Vercel 학생 화면에서는 결과만 보입니다)
- 컴퓨터가 꺼져 있거나 학교망 밖(집, LTE)에서는 볼 수 없습니다. 그럴 땐 위의 Vercel 방법을 함께 쓰세요.
